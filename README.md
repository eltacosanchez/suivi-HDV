# suivi-HDV
Outil Windows gratuit qui relève tout seul les prix de l’Hôtel de vente de Dofus 3 quand tu ouvres une ressource : prix par lot (x1, x10, x100, x1000), prix moyen, évolution et graphiques. Simple lecture de l’écran avec l’OCR de Windows, aucune modification du jeu, aucun clic à ta place. Marche avec le Compteur XP. Projet de fan non officiel.
